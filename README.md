# Ahad Shaikh — Cybersecurity Portfolio 🛡️

> *"Breaking things ethically since 2024."*

A professional, hacker-themed cybersecurity portfolio built with HTML, CSS, and JavaScript. Designed to showcase cybersecurity skills, projects, lab work, and certifications in a clean, modern, terminal-inspired aesthetic.

---

## 🔥 Features

- **Matrix rain canvas background** — animated digital rain effect
- **Preloader with boot sequence** — cinematic system-boot intro animation
- **Typing animation** — dynamic role display
- **Interactive terminal panels** — authentic Kali Linux-style terminals
- **Glitch effect** on hero name — subtle hacker aesthetic
- **3D card tilt** — GPU-accelerated hover effects
- **Scroll-based animations** — smooth reveal on scroll
- **Live TryHackMe badge** — auto-updates with room completions
- **Animated skill bars** — triggered on scroll into view
- **Certification roadmap** — visual learning journey
- **Fully responsive** — mobile, tablet, and desktop

## 📦 How to Deploy

### GitHub Pages
1. Fork or clone this repo
2. Place your `Resume.pdf` in `assets/`
3. Go to **Settings → Pages → Deploy from branch (main)**
4. Your portfolio will be live at `https://yourusername.github.io/repo-name`

### Local Preview
```bash
# Just open index.html in a browser
# Or use a local server (recommended):
python3 -m http.server 8080
# Then visit http://localhost:8080
```

## 🔑 Customization

### Update your info
Edit `index.html` and replace:
- Name, university, degree
- Social links (LinkedIn, GitHub, TryHackMe)
- TryHackMe badge `userPublicId`
- Certification verify links
- Project descriptions and findings
- Contact email

### Change colors
In `style.css`, edit the `:root` variables:
```css
:root {
    --accent: #00e5a0;      /* Main green accent */
    --accent2: #00bfff;     /* Secondary blue accent */
    --bg: #070b10;          /* Background color */
}
```
